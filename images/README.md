# Images Folder

Upload your website images into this folder.

## How to add an image

1. Open this `images` folder on GitHub.
2. Click **Add file** → **Upload files**.
3. Select your image files (JPG, PNG, WEBP, or GIF).
4. Scroll down and click **Commit changes**.

## How to use an image in the website

Use the image path like this in your HTML:

```html
<img src="images/your-image-name.jpg" alt="Describe the image">
```

For CSS backgrounds:

```css
background-image: url("images/your-image-name.jpg");
```

## Tips

- Use simple file names, for example: `poster-01.jpg`, `logo.png`, or `project-cover.webp`.
- Avoid spaces and special characters in file names.
- Keep the file extension exactly as uploaded (`.jpg`, `.png`, etc.).
- After uploading, use the exact same spelling and capital letters in your code.
